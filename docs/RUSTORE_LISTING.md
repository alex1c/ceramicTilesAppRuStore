## Short description

Считает, сколько плитки купить: пол или стены, раскладка, запас, упаковка и цена.

## Full description

Калькулятор плитки помогает оценить, сколько плитки взять в магазине — без сложных терминов и без претензии на CAD-раскрой.

Укажите пол или стены, размер плитки, схему укладки и запас. Для прямой раскладки расчёт учитывает геометрию и подрезку; для диагонали и смещения используется честная оценка по площади с рекомендуемым запасом. Можно учесть упаковку и стоимость.

Результат можно поделиться текстом или PDF. В приложении показывается один рекламный баннер; подключена обезличенная аналитика AppMetrica.

## Features

- Пол и стены, проёмы
- Прямая / диагональ / смещение
- Ориентация прямоугольной плитки
- Запас, упаковка, цена
- Пояснение «Как рассчитано»
- Схема раскладки (не чертёж раскроя)
- Share и PDF

## Ads disclosure

Приложение показывает рекламу Yandex Mobile Ads (один адаптивный баннер).

## Analytics disclosure

Приложение использует Yandex AppMetrica для обезличенной продуктовой статистики.
