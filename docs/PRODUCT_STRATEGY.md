# Product strategy

Calculator Platform: **separate niche Android apps**, not one mega-calculator.

- Market: Russia first
- Store: RuStore first (Google Play / AppGallery later)
- Monetization: advertising (Yandex Mobile Ads). Ads must not block entering sizes or reading the main result. No interstitial before the first result.
- Analytics: AppMetrica, privacy-safe categorical events, no raw dimensions.
- Key metric: Revenue per Install
- Sibling product: Wallpaper Calculator (`wallpaperAppRustore`)
- This app: Tile Calculator — second niche product, **separate repository** (no monorepo yet)
